Monitoring Amazon Web Services (AWS)
====================================

Amazon Web Services (AWS) is a widely used cloud computing platform provided by Amazon. It offers a broad set of services, including computing power, storage, databases, machine learning, analytics, security, and more. AWS enables individuals, businesses, and organizations to access and use computing resources without the need to invest in and maintain physical infrastructure.

Wazuh, an open source security platform, provides a comprehensive suite of features to monitor and improve the security of your AWS infrastructure. You can install Wazuh agents on your EC2 instances or integrate the Wazuh module for AWS with supported AWS services. Both options let you analyze events and get near real-time findings on anomalies within your AWS infrastructure.
