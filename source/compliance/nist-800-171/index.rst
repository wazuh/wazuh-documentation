Using Wazuh for NIST 800-171 compliance
=======================================

NIST Special Publication 800-171 defines security requirements for nonfederal organizations that process, store, or transmit controlled unclassified information (CUI) for the U.S. federal government. Contractors of the U.S. Department of Defense (DoD) must implement these requirements under the Defense Federal Acquisition Regulation Supplement (DFARS) clause 252.204-7012.

This document outlines use cases that show how Wazuh helps you meet NIST SP 800-171 security requirements. Each section describes a requirement, explains how Wazuh supports it, and shows one or more use cases with step-by-step instructions.

.. note::

   These rules and mappings are indicative and do not by themselves certify compliance. See :doc:`Regulatory compliance </compliance/index>` for more details.
