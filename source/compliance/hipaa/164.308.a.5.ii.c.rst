HIPAA § 164.308(a)(5)(ii)(C) - Log-in monitoring
====================================================

The HIPAA § 164.308(a)(5)(ii)(C) requirement states, "*Procedures for monitoring log-in attempts and reporting discrepancies.*"

Wazuh helps meet this requirement with the :doc:`log data analysis </user-manual/capabilities/log-data-collection/index>` capability, which generates findings for successful and failed log-in attempts.

Use case: SSH authentication
-------------------------------

In this use case, Wazuh monitors SSH authentication activity on an Ubuntu 26.04 endpoint and generates findings for successful and failed authentication.

Ubuntu endpoint
^^^^^^^^^^^^^^^^

#. From a different host, attempt an SSH login to the monitored Ubuntu endpoint with valid credentials. Replace ``<USERNAME>`` with an existing user on the endpoint and ``<ENDPOINT_IP>`` with the IP address of the Ubuntu endpoint:

   .. code-block:: console

      $ ssh <USERNAME>@<ENDPOINT_IP>

#. From the same host, run the SSH login again and enter an incorrect password to generate a finding for the failed attempt.

#. Navigate to **Threat intelligence** > **Threat Hunting** > **Findings** to see the findings on the Wazuh dashboard:

   .. thumbnail:: /images/compliance/hipaa/ssh-authentication-finding.png
      :title: Threat Hunting findings - SSH authentication
      :alt: Threat Hunting findings - SSH authentication
      :align: center
      :width: 80%

   The finding includes the username, timestamp, and authentication status (success or failure).
