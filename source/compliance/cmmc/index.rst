Using Wazuh for CMMC compliance
===============================

The Cybersecurity Maturity Model Certification (CMMC) program verifies that contractors of the U.S. Department of Defense (DoD) protect federal contract information (FCI) and controlled unclassified information (CUI).

This document outlines use cases that show how Wazuh helps you meet CMMC security requirements. Each section describes a requirement, explains how Wazuh supports it, and shows one or more use cases with step-by-step instructions.

.. note::

   These rules and mappings are indicative and do not by themselves certify compliance. See :doc:`Regulatory compliance </compliance/index>` for more details.
