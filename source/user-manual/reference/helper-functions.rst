Helper function reference
=========================

The following tables list all 120 helper functions in two categories: 46 check helpers and 74 map helpers. The map helpers are split into 29 helpers that produce a value and 45 helpers that modify the event. Each table lists its helpers in alphabetical order. Each row shows the helper signature, the type and source of each argument, the expected target field type, and the helper's behavior. An example follows each table.

The ``is_*`` helpers and the negated helpers, such as ``is_not_null``, ``not_in_kvdb``, and ``string_ne``, fail when the target field doesn't exist. Only ``not_exists`` passes for a missing field. To negate ``array_contains_all``, write ``NOT array_contains_all(...)`` in a conditional expression. The negation also passes when the target field is missing or isn't an array, or when a referenced element doesn't exist.

The ``number_*`` helpers compare two integers exactly as 64-bit values. When either side has decimals, both sides are compared as floating-point numbers, so ``2`` equals ``2.0`` and ``3`` is greater than ``2.9``. An integer compared with a decimal is exact only up to 2^53, so keep large counters and epoch timestamps as integers on both sides. A string such as ``"2"`` is never a number, so the check fails.

Check helper example
^^^^^^^^^^^^^^^^^^^^

The ``in_cidr`` helper checks whether an IP address belongs to a network. In this decoder ``check``, the decoder accepts only events whose ``_target_field`` is in ``192.168.0.0/16``.

.. code-block:: yaml

   check:
     - _target_field: in_cidr('192.168.0.0/16')

The check passes for the following input event:

.. code-block:: json

   {
     "_target_field": "192.168.1.5"
   }

The decoder rejects the following input event because the check fails:

.. code-block:: json

   {
     "_target_field": "111.111.1.11"
   }

Map helper example
^^^^^^^^^^^^^^^^^^

The ``lowercase`` helper returns its argument in lowercase. In this ``map``, the helper reads ``_upper_characters`` and writes the result to ``_target_field``.

.. code-block:: yaml

   normalize:
     - map:
         - _target_field: lowercase($_upper_characters)

Input event:

.. code-block:: json

   {
     "_upper_characters": "AbcD"
   }

Output event:

.. code-block:: json

   {
     "_upper_characters": "AbcD",
     "_target_field": "abcd"
   }

Example of a map helper that modifies the event
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The ``trim_end`` helper removes characters from the end of the target string. In this ``map``, the helper removes the trailing ``-`` characters from ``_target_field``.

.. code-block:: yaml

   normalize:
     - map:
         - _target_field: trim_end('-')

Input event:

.. code-block:: json

   {
     "_target_field": "-- Hi wazuh! --"
   }

Output event:

.. code-block:: json

   {
     "_target_field": "-- Hi wazuh! "
   }
