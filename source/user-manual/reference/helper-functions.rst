Helper function reference
=========================

This reference lists the helper functions that you use in decoders and filters of the Wazuh normalization engine. For the helper call syntax and an explanation of the arguments, including their types and sources, see :ref:`data_analysis_helper_functions`.

The following tables list all 128 helper functions across three categories: 53 filter, 28 map, and 47 transformation helpers. Each table lists its helpers in alphabetical order. Each row shows the helper signature, the type and source of each argument, the expected target field type, and the helper's behavior. An example follows each table.

.. _helper_functions_filter:

Filter helper example
^^^^^^^^^^^^^^^^^^^^^

The ``ip_cidr_match`` helper checks whether an IP address belongs to a network range. In this decoder ``check``, the decoder accepts only events whose ``_target_field`` is in ``192.168.0.0/16``.

.. code-block:: yaml

   check:
     - _target_field: ip_cidr_match('192.168.0.0', '255.255.0.0')

The check passes for the following input event:

.. code-block:: json

   {
     "_target_field": "192.168.1.5"
   }

The decoder rejects the following input event because the check fails:

.. code-block:: json

   {
     "_target_field": "111.111.1.11"
   }

Map helper example
^^^^^^^^^^^^^^^^^^

The ``downcase`` helper returns its argument in lowercase. In this ``map``, the helper reads ``_upper_characters`` and writes the result to ``_target_field``.

.. code-block:: yaml

   normalize:
     - map:
         - _target_field: downcase($_upper_characters)

Input event:

.. code-block:: json

   {
     "_upper_characters": "AbcD"
   }

Output event:

.. code-block:: json

   {
     "_upper_characters": "AbcD",
     "_target_field": "abcd"
   }

Transformation helper example
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

The ``trim`` helper removes a character from the start, the end, or both ends of the target string. In this ``map``, the helper removes the trailing ``-`` characters from ``_target_field``.

.. code-block:: yaml

   normalize:
     - map:
         - _target_field: trim('end', '-')

Input event:

.. code-block:: json

   {
     "_target_field": "-- Hi wazuh! --"
   }

Output event:

.. code-block:: json

   {
     "_target_field": "-- Hi wazuh! "
   }
