Installation utilities
========================

Wazuh provides installation utilities that are command-line scripts that simplify the deployment, configuration, and initialization of a Wazuh installation.

Unlike the tools included with an installed Wazuh manager or agent, these utilities are used before or during deployment to automate installation tasks, generate certificates, and prepare the required configuration files.

The following installation utilities are available:

- :doc:`Wazuh Installation Assistant <installation-assistant>`
- :doc:`Wazuh certs tool <certs-tools>`
