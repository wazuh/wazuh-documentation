Wazuh manager
=============

The Wazuh manager in Wazuh 5.x introduces changes to its configuration, installation layout, and capabilities. Although you can recreate supported settings from a Wazuh 4.x deployment, Wazuh 5.x removes, relocates, or replaces several configuration sections, options, and features.

Deploy a new Wazuh manager and recreate the supported configuration from the Wazuh 4.x deployment. Don't copy Wazuh 4.x configuration files directly into the new installation, because they contain settings that Wazuh 5.x no longer supports.

You can recreate the following Wazuh manager configuration in Wazuh 5.x:

-  Wazuh manager configuration
-  Internal configuration options
-  Wazuh manager API configuration
-  Cluster configuration

You can't recreate custom rules, decoders, and CDB lists by copying files into the Wazuh manager installation. In Wazuh 5.x, the Wazuh content management system manages custom detection content. Wazuh 5.x stores CDB lists as key-value databases (KVDBs). Refer to the :doc:`Data analysis </user-manual/data-analysis/data-analysis-components>` documentation to learn how to create and manage custom rules, decoders, and lists. Wazuh 5.x decoders write only Wazuh Common Schema (WCS) fields and temporary fields.

.. _migration_wazuh_manager_configuration:

Wazuh manager configuration
---------------------------

The Wazuh manager configuration defines how the manager operates, including agent communication, authentication, vulnerability detection, indexer connectivity, clustering, and other manager services.

Wazuh 4.x and Wazuh 5.x use different configuration structures and supported settings. Therefore, the Wazuh 4.x configuration serves as a reference for recreating the required settings in the corresponding Wazuh 5.x configuration files.

The primary Wazuh manager configuration file has changed between Wazuh 4.x and Wazuh 5.x:

+-------------------------------+-------------------------------------------+
| Wazuh 4.x                     | Wazuh 5.x                                 |
+===============================+===========================================+
| ``/var/ossec/etc/ossec.conf`` | ``/etc/wazuh-manager/wazuh-manager.conf`` |
+-------------------------------+-------------------------------------------+

Configuration changes
---------------------

Review the following changes before you recreate the Wazuh manager configuration. Wazuh 5.x uses ``<wazuh_config>`` as the root element of ``wazuh-manager.conf`` instead of ``<ossec_config>``. The file must have exactly one ``<wazuh_config>`` root element, and each section can appear only once. Wazuh 5.x accepts only the ``<global>``, ``<logging>``, ``<remote>``, ``<auth>``, ``<wdb>``, ``<vulnerability-detection>``, ``<indexer>``, ``<task-manager>``, and ``<cluster>`` sections. Any other section causes a startup error.

.. _migration_unsupported_configuration_sections:

Unsupported and changed settings
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Wazuh 5.x removes, relocates, or changes the following Wazuh 4.x sections and options. Use the table to decide which values from the Wazuh 4.x configuration to set in the Wazuh 5.x file. The Wazuh manager doesn't start if ``wazuh-manager.conf`` contains an option that Wazuh 5.x doesn't support.

+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Wazuh 4.x setting               | Wazuh 5.x change                                                                                                                                                                                                                                                                                                                                                                                                   |
+=================================+====================================================================================================================================================================================================================================================================================================================================================================================================================+
| ``<alerts>``                    | Removed. Wazuh 5.x has no replacement for this section.                                                                                                                                                                                                                                                                                                                                                            |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<rule_test>``                 | Not supported. Remove it from the Wazuh 5.x configuration.                                                                                                                                                                                                                                                                                                                                                         |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<active-response>``           | Active Response configurations are no longer defined in the Wazuh manager configuration. Recreate the required response actions through the Active Response page on the Wazuh dashboard. For more information, see the :doc:`Active response </user-manual/capabilities/active-response/index>` documentation.                                                                                                     |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<command>``                   | Commands are now configured through the Active Response page on the Wazuh dashboard.                                                                                                                                                                                                                                                                                                                               |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<integration>``               | Removed. To send findings to Slack, PagerDuty, Jira, or a webhook, create an :doc:`Alerting monitor </user-manual/wazuh-indexer/modules/alerting>` with a :doc:`Notifications channel </user-manual/wazuh-indexer/modules/notifications>`.                                                                                                                                                                         |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<email_alerts>``              | Removed. To send findings by email, create an :doc:`Alerting monitor </user-manual/wazuh-indexer/modules/alerting>` with an email channel in :doc:`Notifications </user-manual/wazuh-indexer/modules/notifications>`.                                                                                                                                                                                              |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<reports>``                   | Removed. Schedule reports in the :doc:`Reporting module </user-manual/wazuh-indexer/modules/reporting>`.                                                                                                                                                                                                                                                                                                           |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<wodle name="open-scap">``    | Removed. Use :doc:`Security Configuration Assessment (SCA) </user-manual/capabilities/sec-config-assessment/index>`.                                                                                                                                                                                                                                                                                               |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<syslog_output>``             | Not supported. Remove it from the Wazuh 5.x configuration.                                                                                                                                                                                                                                                                                                                                                         |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<agentless>``                 | Not supported. Remove it from the Wazuh 5.x configuration.                                                                                                                                                                                                                                                                                                                                                         |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<ruleset>``                   | Custom rules, decoders, and lists are managed through the Wazuh content management system in Wazuh 5.x. For more information, refer to the :doc:`Data analysis </user-manual/data-analysis/data-analysis-components>` documentation.                                                                                                                                                                               |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<rootcheck>``                 | The Wazuh agent now handles rootcheck.                                                                                                                                                                                                                                                                                                                                                                             |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<syscheck>``                  | The Wazuh agent now handles File Integrity Monitoring (FIM).                                                                                                                                                                                                                                                                                                                                                       |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<sca>``                       | The Wazuh agent now handles Security Configuration Assessment (SCA).                                                                                                                                                                                                                                                                                                                                               |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<wodle name="syscollector">`` | The Wazuh agent now handles Syscollector.                                                                                                                                                                                                                                                                                                                                                                          |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<localfile>``                 | The Wazuh agent now handles log collection.                                                                                                                                                                                                                                                                                                                                                                        |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<global>``                    | Wazuh 5.x supports only ``<agents_disconnection_time>``. Other options, such as ``<agents_disconnection_alert_time>``, ``<jsonout_output>``, ``<alerts_log>``, ``<logall>``, ``<logall_json>``, ``<email_notification>``, and ``<update_check>``, aren't supported.                                                                                                                                                |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| Second ``<global>`` block       | Not supported. Wazuh 5.x accepts one ``<global>`` block, and ``<white_list>`` isn't a Wazuh 5.x option.                                                                                                                                                                                                                                                                                                            |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<remote>``                    | Wazuh 5.x doesn't support ``<connection>``, ``<allowed-ips>``, or ``<denied-ips>``. Listener options, such as ``<port>``, ``<protocol>``, and ``<local_ip>``, go in a ``<legacy>`` block. The ``<queue_size>`` option also goes in ``<legacy>``. Wazuh 5.x has no replacement for a syslog listener (``<connection>syslog</connection>``).                                                                         |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<auth>``                      | Wazuh 5.x doesn't support ``<ssl_auto_negotiate>``. The ``<ciphers>`` option accepts only TLS 1.3 cipher suite names, such as ``TLS_AES_256_GCM_SHA384:TLS_CHACHA20_POLY1305_SHA256:TLS_AES_128_GCM_SHA256``. The certificates are ``/etc/wazuh-manager/certs/remoted.pem`` and ``remoted-key.pem``. Don't copy the Wazuh 4.x ``etc/sslmanager.*`` paths of ``<ssl_manager_cert>`` and ``<ssl_manager_key>``.      |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<vulnerability-detection>``   | Wazuh 5.x doesn't support ``<index-status>``.                                                                                                                                                                                                                                                                                                                                                                      |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<vulnerability-detector>``    | Wazuh 4.4 to 4.7 setting. Not supported. Remove it from the Wazuh 5.x configuration.                                                                                                                                                                                                                                                                                                                               |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<indexer>``                   | Wazuh 5.x doesn't support ``<enabled>``. The certificate paths point to the files in ``/etc/wazuh-manager/certs/``. The files are ``indexer-ca.pem``, ``indexer-connector.pem``, and ``indexer-connector-key.pem``. Keep the Wazuh 5.x ``<ssl>`` paths. Don't use the Wazuh 4.x ``/etc/filebeat/certs``/ paths. If the Wazuh 4.x configuration has no ``<indexer>`` block, keep the Wazuh 5.x ``<indexer>`` block. |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<cluster>``                   | Wazuh 5.x doesn't support ``<disabled>``. Every Wazuh 5.x manager runs as a cluster node. Wazuh 5.x requires ``<key>``. The key must have 32 alphanumeric characters and can't be empty. Keep the ``<name>``, ``<node_name>``, ``<node_type>``, ``<key>``, and ``<nodes>`` values of the Wazuh 5.x cluster. Don't copy them from Wazuh 4.x.                                                                        |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``<agent-upgrade>``             | Moved to the ``<task-manager>`` section as ``<upgrade_enabled>`` and ``<wpk_repository>``. The Wazuh manager doesn't start if ``wazuh-manager.conf`` contains ``<agent-upgrade>``.                                                                                                                                                                                                                                 |
+---------------------------------+--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+

|                                                                                             |                                                                                                      | -  ``monitord.daily_rotations`` to ``wazuh_modules.manager_task_log_daily_rotations``                                                                                                                                                                                                                                                                                                                                                                                                                      |
+---------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
| ``/var/ossec/api/configuration/api.yaml``                                                   | ``/var/wazuh-manager/api/configuration/api.yaml``                                                    | Wazuh 5.x doesn't support ``https.ssl_protocol``, ``experimental_features``, ``upload_configuration.integrations``, or ``upload_configuration.remote_commands``. The default certificate names change to ``apid.pem``, ``apid-key.pem``, and ``root-ca.pem``. In a Wazuh manager cluster, only the master node runs the Wazuh manager API, so recreate ``api.yaml`` on the master node. |

| ``/var/ossec/framework/python/lib/python3.*/site-packages/wazuh/core/cluster/cluster.json`` | ``/var/wazuh-manager/framework/python/lib/python3.12/site-packages/wazuh/core/cluster/cluster.json`` | Use the Wazuh 5.x file as the base. Reapply only the interval values that you changed. Edit only this file, not the copy under ``/var/wazuh-manager/framework/wazuh/core/cluster/``. Reapply your changes after each package upgrade. Don't migrate the Wazuh 4.x ``intervals.worker.sync_agent_groups`` setting.                                                                                                                                                                                          |

Recreate the Wazuh manager configuration
----------------------------------------

Perform the following steps to recreate the Wazuh manager configuration in the Wazuh 5.x deployment.

#. Stop the Wazuh 5.x manager service:

   .. code-block:: console

      # systemctl stop wazuh-manager

#. Review the existing Wazuh 4.x manager configuration in ``/var/ossec/etc/ossec.conf``.

#. Recreate the supported configuration manually in ``/etc/wazuh-manager/wazuh-manager.conf``.

#. Review and update any settings affected by changes in Wazuh 5.x, including renamed file paths and manager-side capabilities.

#. Validate the recreated configuration. The command reports every option that Wazuh 5.x doesn't support, each with its location in the file. Fix them and run the command again until it reports no errors before you start the Wazuh manager:

   .. code-block:: console

      # /var/wazuh-manager/bin/wazuh-manager-conf -f /etc/wazuh-manager/wazuh-manager.conf validate

#. Start the Wazuh 5.x manager service:

   .. code-block:: console

      # systemctl start wazuh-manager

#. Verify that the Wazuh manager starts successfully and that the manager log reports no configuration errors.
